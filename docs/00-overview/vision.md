# 비전

> 상태: 초안 · 갱신: 2026-10-21

## 한 줄 소개

**Synthetix**는 SI/SM 기업을 위한 설치형 ERP입니다. 프로젝트를 중심으로 계약, 인력, 비용을 연결하고, 업무 데이터를 회사 밖으로 내보내지 않는 AI를 업무 흐름 곳곳에 넣습니다.

## 대상 사용자

종업원 50~500명 규모의 SI(시스템 구축)·SM(시스템 운영) 기업 (가정)

| 사용자 | 주로 하는 일 |
|---|---|
| 경영진 | 프로젝트별 손익과 인력 가동률 확인 |
| PM | 계약·일정·투입 인력 관리, 주간 보고 |
| 인사 담당자 | 정규직·계약직·파견·협력사 인력 관리, 계약 만료 대응 |
| 회계 담당자 | 전표 처리, 매출 청구, 클라우드 비용 정산 |
| 일반 직원 | 내 투입 현황 확인, 사내 문서 질의 |

## 해결하려는 문제

1. **프로젝트 정보가 흩어져 있습니다.** 계약서는 파일 서버에, 일정은 엑셀에, 투입 인력은 인사 시스템에 따로 있습니다. 그래서 "이 프로젝트는 지금 이익인가?"라는 질문에 바로 답하기 어렵습니다.
2. **인력 계약 기간을 놓치면 법적 위험이 생깁니다.** 기간제 근로자와 파견 근로자는 2년 사용 제한이 있습니다. 협력사 인력의 투입 기간도 함께 추적해야 합니다.
3. **클라우드 비용이 프로젝트에 귀속되지 않습니다.** AWS·Azure 청구서는 회사 전체 금액으로만 와서, 프로젝트별 원가에 반영되지 않습니다.
4. **생성형 AI를 쓰고 싶어도 데이터 유출이 걱정됩니다.** 계약 금액, 고객사 정보, 개인정보가 외부 LLM으로 나가면 안 됩니다.

## 핵심 가치

- **프로젝트 중심 통합:** 계약, 일정, 인력 투입(M/M), 매출, 원가, 클라우드 비용이 모두 프로젝트로 연결됩니다.
- **업무 속 AI:** AI는 챗봇에만 있지 않습니다. 계약서 정보 추출, 일정 위험 감지, 비용 이상 설명처럼 업무 화면 안에서 동작합니다. 원칙은 **AI가 제안하고 사람이 승인**하는 것입니다.
- **데이터 주권:** 로컬 LLM을 쓰고, 모든 AI 호출이 AI Gateway의 비식별화와 검열을 거칩니다. 외부 전송은 기본적으로 차단합니다.

## 비목표 (당분간 하지 않는 것)

- 완전한 회계 패키지 (재무제표 공시, 세무 신고 자동화)
- 급여 계산, 4대보험 신고
- 그룹웨어 전체 기능 (전자결재, 메일)
- 멀티테넌트 SaaS. 현재는 회사별 설치형만 지원합니다. ([ADR-0002](../adr/0002-single-tenant-deployment.md))

## 포트폴리오로서 보여줄 역량

- C#/.NET 풀스택: 서버와 클라이언트(데스크톱·웹)가 DTO와 검증 규칙을 공유
- 모듈형 모놀리스 설계와, 테스트로 강제하는 모듈 경계
- 보안: MFA, 토큰 회전, 데이터 분류와 암호화, 감사 로그
- 책임 있는 AI: 로컬 LLM, 비식별화 파이프라인, Human-in-the-loop, 평가셋
- 실제 업무 지식: SI 계약 형태, M/M, 파견법·기간제법, FinOps
